# 文字組みメモ

文字の大きさ・行間・字間・書体・配色を自分好みにできるメモ帳です。Claude がなくても、ブラウザだけで動きます。書いたメモはその端末の中に保存され、どこにも送信されません。

フォルダの中身は、アプリ本体の `index.html`、電波がなくても開けるようにする `sw.js`、ホーム画面に追加したときの名前とアイコンになる `manifest.webmanifest` と `icon-*.png` です。

## パソコンで使う

`index.html`（または単体の `文字組みメモ.html`）をダブルクリックして、Chrome・Edge・Safari などのブラウザで開くだけです。次からも同じファイルを同じブラウザで開いてください。ブックマークしておくと便利です。

## iPhone・Android で使う

スマホでは HTML ファイルを直接開いてもアプリとして動かないため、無料の GitHub Pages にファイルを置いて、ブラウザで開きます。パソコンがなくても、スマホだけでできます。置いたアプリのファイルは誰でも見られる状態になりますが、書いたメモは各自の端末の中に保存されるので、公開されることはありません。

1. https://github.com でアカウントを作ります。
2. https://github.com/new を開き、Repository name に `mojimemo` などと入れて、Public のまま「Create repository」を押します。
3. 「ファイル」アプリで zip をタップして展開します。
4. 作ったリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を押し、展開したフォルダの中のファイルをすべて選んでアップロードして、「Commit changes」を押します。
5. リポジトリの「Settings」→「Pages」を開き、Branch を「main」と「/ (root)」にして「Save」を押します。
6. 1〜2分待つと、`https://ユーザー名.github.io/mojimemo/` でアプリが開けるようになります（Pages の画面の上にも表示されます）。
7. iPhone は Safari で開き、共有ボタン →「ホーム画面に追加」を選びます。Android は Chrome のメニュー →「ホーム画面に追加」（または「アプリをインストール」）を選びます。

ホーム画面から一度開けば、次からは電波がなくても使えます。明朝・丸ゴシック・UDゴシック・手書き風の書体は、最初に選んだときにインターネットから読み込み、その後は端末に保存されます。

## 保存について

メモは書くたびに自動で保存され、編集画面の上に「保存済み」と表示されます。パソコンでは Ctrl+S（Mac は ⌘S）を押しても保存できます。

編集画面の上にある保存ボタン（下向きの矢印）を押すと、そのメモをテキストファイル（.txt）として保存できます。ファイル名はメモの1行目になります。スマホでは共有画面が開くので、「"ファイル"に保存」を選んでください。

表示設定（右上の Aa）のいちばん下にある「データの保存」では、すべてのメモをまとめたバックアップファイル（.json）の保存と、バックアップからの読み込みができます。読み込むと、手元にないメモが追加され、同じメモは新しいほうが残ります。手元のメモが消えることはありません。

## 気をつけること

ブラウザの閲覧データを消去すると、メモも消えます。ときどきバックアップを保存しておいてください。

保存場所は開き方ごとに別々です。たとえば iPhone では、Safari で開いたときとホーム画面から開いたときで、メモは共有されません。いつも同じ開き方で使い、別の開き方へメモを移したいときは、バックアップを保存して、移したい側で読み込んでください。また Safari は、しばらく開いていないサイトの保存データを消すことがあるので、iPhone ではホーム画面に追加して使うのがおすすめです。
